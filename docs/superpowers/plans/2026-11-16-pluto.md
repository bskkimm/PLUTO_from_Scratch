# PLUTO Implementation Plan

Goal: build an inspectable PyTorch educational implementation of PLUTO with an offline CPU path.

1. Map paper and released implementation; pin their revisions and document variants.
2. Implement masked vector scene encoding, factorized reference-line/longitudinal decoding, prediction, fallback, and paper losses. Check shapes, masks, geometry and gradients.
3. Add deterministic synthetic data, training, atomic epoch checkpoints and diagnostic evaluation. Verify recovery and CLI execution.
4. Provide a self-contained teaching notebook, tests and evidence. Document all unimplemented real-data, simulation, tracking and review gates.

Constraints: do not download data or start full training; no claims of official parity or reproduction without the corresponding tests. Use the released 128-dimensional, 4-layer, 12-mode, 80-step configuration as a reference; smaller smoke configuration for CPU.
